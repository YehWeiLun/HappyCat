# HappyCat

在地圖上遇見 3D 小貓。根目錄 `index.html` 是版本入口，純靜態檔案可直接用 GitHub Pages 發布。

## 版本

- [`v1/`](./v1/)：在 MapLibre 地圖上操控小貓，切換第一人稱與第三人稱視角。
- [`v2/`](./v2/)：從自己的視線預覽地圖，可啟用手機定位與方向感測，靜止後召喚小貓。手機上的詳細資訊與移動說明可收合；AR／XR 入口暫不開放。

兩版各自使用 `index.html`、`style.css` 和 `app.js`。共用貓模型放在 `assets/cat_v01.glb`，由各版的 JS 以模組路徑載入。Three.js 與 MapLibre GL JS 由 CDN 載入。

## V1 操作

| 桌機 | 手機 | 功能 |
| --- | --- | --- |
| W A S D／方向鍵 | 左下搖桿 | 移動（依鏡頭方向） |
| R | 跑步 按鈕 | 切換走路／跑步 |
| Space | 跳 按鈕 | 跳躍 |
| Ctrl | 趴下 按鈕 | 趴下休息／起身 |
| Tab | 視角 按鈕 | 第一／第三人稱 |
| M | 右上「底圖」選單 | 切換街道地圖、臺灣通用電子地圖、正射影像 |
| B | 右上「分棟建物框」 | 顯示／隱藏建物範圍線 |
| 滑鼠移動（點畫面鎖定，Esc 釋放） | 單指拖曳 | 轉向與仰角 |
| 滾輪 | 雙指縮放 | 第三人稱鏡頭遠近 |

小貓的位置、朝向、走／跑、是否趴著、視角與鏡頭角度會存在瀏覽器的 localStorage，下次開啟會回到原位；「回到起點」可重設。若起點或存檔位置落在建物內，會自動移到附近的建物外。小貓無法穿過建物，沿牆移動時會貼著牆邊走。
底圖預設為正射影像。右上「圖層」按鈕可切換底圖與建物框，選擇後選單會收起；選擇也會保存。測繪中心影像圖磚最高為第 19 級；地圖放大時會使用該級圖磚延伸顯示。

## V2 操作

開始第一人稱預覽後，可拖曳畫面或使用 WASD／移動按鈕調整位置與方向。展開「定位、手機方向、底圖」可啟用 GPS、手機方向感測與北方校正。「我已靜止」會在 3 秒後於視線前方召喚小貓。方位與仰角顯示到小數點第一位，方向感測有平滑與微幅變動抑制。

## 本機預覽

GLB 需透過 HTTP 載入，不能直接雙擊 HTML：

```sh
npx serve .
```

## 素材與授權

- `assets/cat_v01.glb`：本專案自製的低面數貓咪模型與九段動畫，供 V1、V2 共用。
- 底圖：[OpenFreeMap](https://openfreemap.org/) liberty 樣式，資料 © OpenStreetMap contributors。
- 臺灣通用電子地圖（`EMAP`）、正射影像（`PHOTO2`）、影像上的透明地圖標註（`EMAP2`）與分棟建物框（`BUILDX`）：[內政部國土測繪中心 WMTS](https://maps.nlsc.gov.tw/S09SOA/pro/Wmts_ajax_main.jsp)。直接介接公開服務，未將圖磚儲存在本專案。
- 建物碰撞使用街道底圖的 OpenMapTiles `building` 向量輪廓。這份輪廓與測繪中心的影像、分棟建物框可能略有差異；分棟建物框開關只影響畫面顯示。
